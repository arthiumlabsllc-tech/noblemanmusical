# Components

## Overview

Component library organized by domain and concern.

## Structure

### `components/ui/`
shadcn/ui primitives (Button, Input, Dialog, etc.)

### `components/brand/`
Brand identity components
- `logo.tsx` — Placeholder logo (TODO(client): replace with final SVG)
- `gold-divider.tsx` — Decorative gold divider
- `brand-pattern.tsx` — Background pattern

### `components/layout/`
Layout chrome
- `top-utility-bar.tsx` — Tier 1 header
- `navbar.tsx` — Main header (Tier 2)
- `category-nav-row.tsx` — Category nav (Tier 3)
- `mega-menu.tsx` — Category mega menu
- `brand-mega-menu.tsx` — Brand mega menu
- `mobile-tab-bar.tsx` — Mobile bottom navigation
- `mobile-drawer.tsx` — Mobile slide-out drawer
- `footer.tsx` — Site footer
- `header-search.tsx` — Search bar in header
- `header-contact.tsx` — Contact block in header
- `cookie-consent.tsx` — Cookie consent banner
- `back-to-top.tsx` — Back to top button
- `live-chat-widget.tsx` — WhatsApp chat widget
- `route-chrome.tsx` — Route wrapper
